# 오픈놀 커리어링크 참여자 페이지

수료생이 로그인해 취업 현황 조사에 응답하고, 상태에 맞는 사후관리 서비스를 보는 페이지입니다. 관리자 페이지와 같은 Supabase 프로젝트를 씁니다.

## 동작 방식

- 로그인은 Supabase Auth(이메일 + 비밀번호)입니다.
- 가입한 계정은 관리자가 보낸 **연결 코드 + 생년월일**을 입력하거나, **연결 요청**을 관리자가 승인해야 기존 관리번호와 연결됩니다. 이름·연락처만으로 자동 연결하지 않습니다.
- 참여자는 테이블을 직접 읽지 못하고 `p_`로 시작하는 DB 함수로 **본인 정보만** 다룹니다.
- 조사 응답은 제출 즉시 참여자 DB에 반영되고, 바뀐 항목은 관리자 페이지 변경 이력에 '설문 반영'으로 남습니다.

## 보안 규칙

- `config.js`에는 공개 키만 넣습니다. service_role 키, `sb_secret_...` 키는 절대 넣지 않습니다.
- 이 저장소에는 명단, 연결 코드 엑셀, 응답 파일을 올리지 않습니다. `.gitignore`가 엑셀·CSV를 막아 둡니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 참여자 페이지 전체 |
| `config.js` | Supabase 연결 설정(공개 키만) |
| `.gitignore` | 개인정보 파일 업로드 방지 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 내보내도록 하는 설정 |
